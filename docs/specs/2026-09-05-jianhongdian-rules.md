## 一、基本玩法（預設）

- **人數**：2 到 4 人（`seats: { min: 2, max: 4, fixed: false }`）。開局時以入座人數決定發牌張數。
- **牌**：52 張。桌面攤 4 張明牌，牌堆固定 24 張，剩下的平分給玩家：

| 人數 | 每人手牌 | 桌面 | 牌堆 | 每人翻牌次數 |
|---|---|---|---|---|
| 4 | 6 | 4 | 24 | 6 |
| 3 | 8 | 4 | 24 | 8 |
| 2 | 12 | 4 | 24 | 12 |

- **順序**：第一局由席位順序第一位先出，之後每局首家輪替一位。首家的前一位是**尾家**（每局最後一個行動的人）。
- **一手**：輪到的人做兩件事，前端與 MCP 都當成一個動作 `play_card`：
  1. 出一張手牌。手牌若和桌面某張配對，可以收走兩張（配對是選擇，不是義務；有多張可配時自己挑一張）；不配對或配不到就把手牌留在桌上。
  2. 翻牌堆最上面一張。翻出的牌和桌面配得到就收走兩張，配不到就留在桌上。翻出的牌只跟桌面配，不跟手牌配。翻牌自動進行，多張可配時自動收分數最高的那張（同分取先攤在桌上的）。
- **配對**：A 到 9 兩張湊十（A 配 9、2 配 8、3 配 7、4 配 6、5 配 5）；10、J、Q、K 只能同點配。花色不限。
- **一局結束**：牌堆翻完、手牌出完（人數不論，最後一翻剛好是尾家的）。桌面剩下的牌不歸任何人。
- **叨牌**（童童家規，預設開）：尾家可以看牌堆最後一張，因為最後一翻是他的。只有尾家的視角看得到 `board.bottom_card`，其他人看不到。

### 分數牌

| 牌 | 分 |
|---|---|
| ♥A、♦A | 各 20 |
| 紅色 9、10、J、Q、K | 各 10 |
| 紅色 2 到 8 | 牌面數字 |
| ♠A | 30（依 `black_ace` 開關） |
| ♣A | 40（依 `black_ace` 開關） |
| 其餘黑牌 | 0 |

紅牌合計 210。

### 一局的分數

每局分數 = 實得分 − 基準分，基準分 = 全部分數牌總分 ÷ 人數，四家（或三家、兩家）加總為 0。

| `black_ace` | 總分 | 4 人基準 | 3 人基準 | 2 人基準 |
|---|---|---|---|---|
| `both`（預設：♠A 30 + ♣A 40） | 280 | 70 | 93.3 | 140 |
| `spade`（只有 ♠A 30） | 240 | 60 | 80 | 120 |
| `none`（黑牌不計分） | 210 | 52.5 | 70 | 105 |

不整除的基準保留一位小數，每局分數四捨五入到一位小數後累加。

### 累積與結束

分數逐局累加。結束條件沿用拱豬的桌面選項：局數制（預設，打滿 4 局結算）或分數制（任一家累積分達到 `end_score`，預設 100）。整場結束時累積分最高者勝。

## 二、桌面選項

| key | 名稱 | 型別 | 說明 |
|---|---|---|---|
| `end_mode` | 結束方式 | choice | `rounds`（預設）／`score` |
| `end_rounds` | 結束局數 | number | 預設 4，只在局數制顯示 |
| `end_score` | 結束分數 | number | 預設 100，只在分數制顯示；任一家累積分達到就結束 |
| `black_ace` | 黑 A 計分 | choice | `both`（預設）：♠A 30、♣A 40；`spade`：只有 ♠A 30；`none`：黑牌不計分 |
| `peek_bottom` | 叨牌 | boolean | 預設開；尾家看得到牌堆最後一張 |

「摃」（一次吃光桌面加獎勵、連翻兩張）與「雙紅 5 罰分」童童家沒玩，不做也不做開關。

## 三、引擎對應

- mode `jianhongdian`、label「撿紅點」、`rules_version: "jianhongdian-tw-1"`。
- 不是吃墩遊戲，不用 `trick-taking-core`；配對與計分寫在 `src/engine/jianhongdian-engine.ts` 與 `jianhongdian-rules.ts`。

### 狀態

```ts
interface JianhongdianState {
  phase: "play" | "ended";
  order: string[];                       // 本局行動順序，order[0] 是首家、最後一位是尾家
  hands: Record<string, string[]>;
  table: string[];                       // 桌面明牌，依攤出順序
  pile: string[];                        // 牌堆，pile[0] 是下一張要翻的、最後一張是叨牌看得到的
  captured: Record<string, string[]>;    // 各家收走的牌
  active: string | null;
  lastFlip: { seatId: string; card: string; captured: string | null } | null;   // 前端顯示「翻出 ♦7，收走 ♠3」用
}
```

### legal_plays 與 legal_actions

- 輪到的人 `legal_actions` 只有 `play_card`。
- `legal_plays` 每筆一個 `cards` 陣列：`[手牌]` 表示放到桌上，`[手牌, 桌面牌]` 表示配對收走。每張手牌至少有 `[手牌]` 一筆，配得到的另外每張桌面牌各一筆。AI 只從清單挑；伺服器驗證。
- `apply` 一次完成「出牌（配或不配）→ 翻牌自動配」兩步，`lastFlip` 記翻牌結果，事件文字：「{name} 用 ♥3 收走 ♠7，翻出 ♦A 收走 ♣9。」

### board

```ts
{
  phase, table: string[], pile_count: number,
  captured_points: Record<seat, string[]>,   // 各家已收的分數牌（只露分數牌）
  captured_count: Record<seat, number>,
  last_flip: { seat_id, card, captured } | null,
  bottom_card: string | null,                // 只有尾家且 peek_bottom 開時有值
  last_round_scores?: Record<seat, number>,
}
```

### 結算

`scoreRound(captured, options, playerCount)` 純函式匯出：算各家實得、減基準、四捨五入一位小數。`isGameOver` 沿用拱豬寫法，分數制改成「任一家累積分 ≥ end_score」。

### 離桌

局中離桌一律 `"abort"`（流局），與代打搭配；`transferSeat` 換 id 不換位。

## 四、前端

- 桌面中央攤明牌（依攤出順序），右上角顯示牌堆剩餘張數；尾家開叨牌時在牌堆旁翻開最後一張。
- 每家名字旁顯示已收的分數牌小圖示與本局實得分。
- 出牌：點手牌選起來，桌面可配的牌亮起；點桌面牌就配對收走，點「放到桌上」就不配。只有一筆合法選項時（配不到）點手牌直接出。
- 翻牌結果用桌面上的一行字呈現：「翻出 ♦A，收走 ♣9」，停留到下一手。
- 開桌表單由 `/api/games` 生成：黑 A 計分是三段切換按鈕，結束方式沿用拱豬的顯示規則。

## 五、童童的答覆（2026-09-05）

1. 黑 A 計分：三種都做成開關（`black_ace`）。
2. 人數：2 到 4 人都做。
3. 摃與雙紅 5：家裡沒玩，不做。
4. 整場結束：沿用拱豬的分數制／局數制，預設局數制 4 局。
5. 家規「叨牌」：尾家可以看牌堆最後一張（`peek_bottom`，預設開）。

## 六、待童童確認的三個設計取捨

1. **配對是選擇不是義務**：手牌配得到也可以不配、放到桌上（真人玩法通常允許，這樣也給 AI 留戰術空間）。
2. **翻牌多張可配時自動收分數最高的**：不多一個「選哪張」的步驟，人類與 AI 都省一手。
3. **不整除的基準保留一位小數**（3 人黑 A 全計 93.3、4 人黑牌不計 52.5）：累積分會出現小數。另一條路是「每局分數乘以人數」讓分數全是整數，但數字會跟真人算的對不上。
