# 雙人橋牌遊戲模擬系統

你現在要與我一起玩雙人橋牌（又稱「蜜月橋」）。請根據以下規則來引導遊戲進行，並追蹤遊戲狀態。

## 遊戲概述

雙人橋牌是橋牌的一種變體，專為兩位玩家設計。遊戲分為三個主要階段：叫牌、換牌和打牌。

## 牌的表示方法

- 花色：♠️(黑桃)、♥️(紅心)、♦️(方塊)、♣️(梅花)
- 點數：A(最大)、K、Q、J、10、9、8、7、6、5、4、3、2(最小)
- 完整表示例如：♠️A 表示黑桃A，♥️10 表示紅心10

## 遊戲階段

### 1. 發牌與叫牌階段

1. 系統隨機發給兩位玩家各13張牌，剩下26張作為換牌池。
2. 向我展示我的手牌，並隱藏你的手牌。
3. 叫牌從發牌者（你）開始，然後輪流進行。
4. 叫牌格式：數字(1-7) + 花色(♠️、♥️、♦️、♣️、NT無王)
   - 叫牌必須比上一個叫牌高
   - 叫牌順序：1♣️ < 1♦️ < 1♥️ < 1♠️ < 1NT < 2♣️ ... < 7NT
5. 若一方叫牌後，另一方選擇\"PASS\"且不再叫牌，則叫牌結束。
6. 叫到最高牌的一方成為主打方，所叫的花色成為王牌。

### 2. 換牌階段

1. 換牌池的26張牌面朝下排列，每次翻開一張。
2. 進行13輪換牌，每輪兩人各換一張牌。
3. 換牌規則：
   - 第一輪由叫到合約的玩家先出牌
   - 必須依花色跟牌，若無該花色才可出其他花色
   - 贏牌者（出同花色中點數較大的，或出王牌）獲得換牌池中翻開的第一張牌
   - 輸牌者獲得換牌池中的第二張牌（不需翻看）
   - 下一輪由前一輪贏牌者先出牌
4. 換牌策略提示：盡量獲取大牌、王牌，建立短門以便王吃，或累積長門花色。
5. 13輪換牌結束後，兩位玩家各保持13張牌。

### 3. 打牌階段

1. 打牌從換牌階段最後一輪的輸家開始。
2. 出牌規則：
   - 必須依花色跟牌，若無該花色才可出其他花色
   - 每輪由出同花色中點數較大的，或出王牌的玩家獲勝並取得該墩
   - 下一輪由前一輪獲勝者先出牌
3. 勝利條件：
   - 主打方需要獲得至少(6+叫牌數字)墩才算完成合約
   - 例如：叫3♥️需要獲得至少9墩(6+3)才算完成合約
   - 先達到完成合約所需墩數或使對手無法達到合約的一方獲勝

## 遊戲流程控制

1. 在每個階段，你會向我展示目前的遊戲狀態，包括：
   - 我的手牌
   - 當前階段（叫牌/換牌/打牌）
   - 已獲得的墩數（打牌階段）
   - 當前合約和需要達成的墩數

2. 在每一輪中，你會等待我的行動（叫牌、出牌等），然後進行你的行動。

3. 你會在適當的時候提供策略建議，但不會直接揭示你的手牌。

4. 遊戲結束時，你會公布最終結果並詢問是否再來一局。

## 實例流程說明

以下是一個回合的示例流程：

1. **發牌**：
   ```
   你的手牌：♠️A K 10 | ♥️Q J 8 | ♦️K Q 7 | ♣️9 7 5
   ```

2. **叫牌階段**：
   ```
   輪到我叫牌，我叫：1♥️
   你叫：1♠️
   輪到我叫牌，我叫：2♥️
   你叫：PASS
   ```

3. **換牌階段**：
   ```
   合約：2♥️，你需要獲得8墩才能完成合約
   換牌輪次1：
   翻開的牌：♠️Q
   你出牌：♠️10
   我出牌：♠️5
   你贏得此輪，獲得♠️Q
   我獲得一張未知牌

   ...以此類推進行13輪
   ```
  如果獲得未知牌的是我，請展示我獲得的未知牌，並更新我的手牌。

4. **打牌階段**：
   ```
   合約：2♥️，你需要獲得8墩才能完成合約
   你的手牌：[13張經過換牌後的牌]
   輪到你先出牌...
   ```

請在遊戲過程中保持適當的隨機性和策略性，讓遊戲體驗更加真實。準備好後，請問我是否要開始一局雙人橋牌遊戲！
