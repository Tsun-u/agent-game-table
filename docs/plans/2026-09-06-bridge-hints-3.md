### 任務 2：通用規則（小葵）

**檔案：** 修改 `src/engine/bridge-systems.ts`

- [x] 步驟 1：**估搭檔最低點數** `partnerMinimum(partnerCalls)`：取搭檔叫過的所有聲音中最大的估計值：一線花色開叫 12、1NT 開叫 15（taiwan_5533 16）、2♣ 22、2NT 20、3NT 25、弱二 5、三線阻擊 5、一線蓋叫 8、二線蓋叫 10、1NT 蓋叫 15、技術性 Double 12、對開叫的單加叫 6、限制性加叫 10、Jacoby 2NT 13、一線新花應叫 6、二線新花應叫 10、對 1NT 的 2NT 8、3NT 10、對搭檔蓋叫的加叫 6、叫對手花色 10、任何跳叫 16（開叫者）／10（應叫者）、PASS 0。搭檔沒叫過就是 0。
- [x] 步驟 2：**配合判斷** `agreedSuit()`：依序找第一個成立的：(a) 雙方都叫過的花色；(b) 搭檔第一門花色是五張以上承諾（一線高花開叫、花色蓋叫、弱二、三線阻擊、轉換後的高花）且自己 ≥ 3 張；(c) 自己第一門花色被搭檔加叫過；(d) 搭檔第一門是一線低花開叫且自己 ≥ 5 張。都沒有 → null。
- [x] 步驟 3：**通用規則** `generalRound()`（既有處境都不符合時）：
  1. 算 `combined = hcp + partnerMinimum`、`agreed`、`ourHighest`（我方最高叫品）、`theirHighest`（對方最高叫品）、`highest`
  2. 我方已到成局或以上（`ourHighest` 是 3NT／4♥／4♠／5♣／5♦ 或更高）→ `PASS`「已經成局，守住」
  3. `agreed` 是高花且 combined ≥ 25 → `4M`「合計約 N 點、有配合，叫成局」（若 4M 不比 highest 高就 `PASS`）；`agreed` 是低花且 combined ≥ 28 → `5m`；`agreed` 是低花且 combined ≥ 25 且平均 → `3NT`
  4. 沒有 `agreed`、combined ≥ 25、平均、對手叫過的花色自己都 ≥ 2 張 → `3NT`
  5. 對手持有最高叫品且有 `agreed`：總墩數法則，自己該花色張數 ＋ 搭檔假設張數（五張承諾 5、弱二 6、加叫 3、其餘 4）≥ 下一個可叫線位 ＋ 6 → 叫該花色最低合法線位「競叫，我方合計約 N 張」；否則 `PASS`
  6. 對手持有最高叫品、沒有 `agreed`、自己 6+ 張花色且 combined ≥ 20、該花色最低合法線位 ≤ 3 → 叫它
  7. 我方持有最高叫品、combined ≥ 23 且 < 25、有 `agreed` 高花、可叫 `3M` 邀請且自己還沒叫過邀請 → `3M`「邀請成局」
  8. 否則 `PASS`「已足夠，守住目前合約」
- [x] 步驟 4：`suggestCall` 分派：既有八種 → 任務 1 的處境 → `generalRound`。不再有回 null 的分支；合法性過濾照舊（過濾掉就 null，前端仍顯示「這一輪沒有建議」）。
