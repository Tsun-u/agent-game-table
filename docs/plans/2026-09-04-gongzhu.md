# 拱豬與傷心小棧 實作計畫

> **給執行者：** 使用「執行計畫」skill 逐步完成此計畫。步驟使用 checkbox（`- [ ]`）格式追蹤進度。
> 執行紀錄：2026-09-04 完成；前端未拆檔（app.js 內依 mode 分路）、未加拱豬 e2e（手動驗過），其餘全部完成。
> 規則依據：`docs/specs/2026-09-04-gongzhu-rules.md`（童童 2026-09-04 核可）。引擎介面：`src/engine/types.ts`（已落地，f81cf4b）。

**目標：** 大廳可以開「拱豬」或「傷心小棧」桌，人類與 AI 都能打完整場（含傷心小棧的傳牌與射月），結束條件可選分數制或局數制。

**方法：** 先擴充引擎介面（數字選項、整場結束判斷），再做吃墩共用核心與拱豬引擎並用純函式測試釘住計分，接著牌桌層接上整場結束，最後做前端桌面。每個任務結束都跑 `npm test`。

**工具／技術：** TypeScript、node:test、Playwright e2e、既有 PAT push 流程。
